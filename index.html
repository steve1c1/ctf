Scoring protocol

No random numbers. Operator scores are calculated with a transparent formula — same spirit as CTFd dynamic scoring, tuned for our syndicate.

> base points by difficulty

WARMUP100 pts
EASY250 pts
MEDIUM500 pts
HARD750 pts
INSANE1000 pts

> bonuses

FIRST BLOOD (global 1st solve)+100
SOLO SOLVE (only operator on it)+50
WRITEUP PUBLISHED+25
MVP OF THE EVENT+200

> event multipliers

LOCAL / PRACTICE×1.0
NATIONAL×1.5
INTERNATIONAL×2.0
INVITE-ONLY×2.5
GRAND FINALS×3.0

> the formula

# dynamic scoring (anti-camping decay) points = base × (1 − 0.75 × solves/150) points = max(points, base × 0.25) # floor # per solve earned = (points + bonuses) × event_multiplier # operator score score = Σ earned # across all CTFs

> backend — supabase setup

STEP 1. Create a free project at supabase.com → copy your Project URL and anon public key.
STEP 2. SQL Editor → run the schema below (creates tables + row policies + profile triggers).
STEP 3. Open index.html, find SUPABASE_URL + SUPABASE_ANON_KEY at the top of the script, paste your values, redeploy. Auth & data go live.
STEP 4. Auth → Users → "Add user" to create operator accounts (set email + temp password). They appear here automatically.
Without keys the site runs in DEMO MODE (localStorage on this device — perfect for testing everything).
